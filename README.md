# book-skill-kit · 把一本书变成可检索的技能（工具骨架）

一个零依赖的小工具骨架，用来把**你自己合法持有的电子书**变成一套"可对话的技能"：文本切片 → 建立锚点 → 检索定位 → 基于原文回答，且每条结论都能反查出处。

> 本仓库**只包含工具与方法**，不含任何书籍正文。

## 包含什么

| 文件 | 说明 |
|---|---|
| `scripts/locate.py` | 全文定位引擎。关键词检索 / 锚点取文 / 篇目列表，纯标准库，含 `--self-test` |
| `SKILL.md` | 技能说明书模板。定义工作流（检索→定位→精读→作答）与硬约束（带锚点、引用上限、超范围明说） |
| `README.md` | 本文档 |

## 不包含什么

- **任何书籍正文、扫描件、电子书文件**。
- 任何从受版权保护作品中提取的成段内容。

本仓库刻意不含书：这样任何人都可以拿它处理**自己有权使用的文本**，而仓库本身保持干净、可自由分发。

## 快速开始

```bash
# 1. 准备你的文本（自己合法持有）
#    期望格式：每个章节以标记行分隔
#    ===== [序号] 文件名 =====
#    （正文）

# 2. 检索
python scripts/locate.py --data /path/to/your_book.txt --query "关键词 另一关键词" --top 5

# 3. 取回命中章节全文
python scripts/locate.py --data /path/to/your_book.txt --anchor S019 --limit 20000

# 4. 自检
python scripts/locate.py --self-test
```

把 `SKILL.md` 放进你的技能目录（如 `~/.workbuddy/skills/<name>/`），按实际书名与文件路径改一遍，即可让 AI 基于这本书作答。

## 为什么不做成"某本书专用仓库"

本仓库最初的形态是一个《毛泽东选集》问答技能。**没有发布那个版本**，原因很直接：

- 《毛泽东选集》1–5 卷是受版权保护的作品（毛泽东 1976 年逝世，中国著作权保护期为作者终生加死后 50 年，**至 2026-12-31 届满**）。
- 把全书正文（约 105 万字）推上公开仓库，属于对该作品的公开再发布。
- 因此本项目改为只开放**工具与方法**：代码归作者，书归权利人，各自边界清晰。

## 使用须知

- 单条引用建议不超过 100 字，不得整段复制原文。
- 用于正式引用前，请核对权威版本（不同版次篇目与注释可能有差异）。
- 发布基于某本书的衍生成果前，请确认你有相应授权，或该书已进入公有领域。
